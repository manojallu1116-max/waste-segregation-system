# Waste Segregation System

A web-based complaint and waste management system developed using **PHP and MySQL**.

## Features
- User Registration & Login
- Waste Complaint Submission
- Admin Dashboard
- Complaint Status Tracking
- Waste Type Categorization

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- XAMPP

## How to Run
1. Install XAMPP
2. Move project to `htdocs`
3. Import database `waste_system`
4. Run `http://localhost/waste-segregation-system`
